[![Python](https://img.shields.io/badge/Python-3.10+-blue?logo=python)](https://www.python.org/)

**Nistone Delivery** — это комплексная система для управления заказами доставки, объединяющая Telegram-бота для клиентов и веб-интерфейс для курьеров и администраторов.

---

## 📋 Описание проекта

Проект решает задачу упрощения создания и отслеживания заказов на доставку. Пользователи взаимодействуют с ботом, а сотрудники компании (курьеры и менеджеры) используют веб-панель для управления заказами в реальном времени.

### Ключевые функции:
- **Создание заказа через Telegram-бота**: пользователь указывает адрес, телефон, сумму, желаемый интервал доставки и комментарий.
- **Отслеживание статуса**: клиенты могут проверить статус своего заказа как в боте, так и на специальной веб-странице.
- **Ролевая модель доступа**:
  - **Курьер** видит в веб-интерфейсе только свои активные заказы.
  - **Администратор** имеет доступ ко всем заказам системы для контроля и управления.
- **Веб-интерфейс на FastAPI** для удобного просмотра и фильтрации заказов.

## 🛠️ Установка и запуск

Следуйте инструкциям ниже, чтобы развернуть проект локально или на сервере.

### Предварительные требования
- Установленный Python 3.10+
- Установленный менеджер пакетов `pip`
- *(Опционально)* Установленный и запущенный сервер базы данных

### Шаг 1: Клонирование репозитория
bash
git clone https://github.com/DKhablo/nistone_dilivery.git
cd nistone_dilivery

### Шаг 2: Настройка виртуального окружения
bash
python -m venv venv
source venv/bin/activate  # Для Linux/macOS
# venv\Scripts\activate   # Для Windows

### Шаг 3: Установка зависимостей
bash
pip install -r requirements.txt

### Шаг 4: Настройка переменных окружения
Создайте файл .env в корневой директории и заполните его своими данными. Пример содержимого:

env
# Telegram Bot
BOT_TOKEN=ваш_токен_бота

# Настройки базы данных
DATABASE_URL=sqlite:///./nistone.db  # или postgresql://user:pass@localhost/dbname

# Секретный ключ для FastAPI (для сессий/токенов)
SECRET_KEY=ваш_секретный_ключ

# Другие настройки
ADMIN_IDS=123456789,987654321  # ID администраторов в Telegram
Шаг 5: Применение миграций (если используются)
bash
# Пример для Alembic
alembic upgrade head
Шаг 6: Запуск приложения
Запуск Telegram-бота:
bash
python bot.py
Запуск веб-сервера (FastAPI):
bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
После запуска веб-интерфейс будет доступен по адресу: http://localhost:8000

📖 Использование
🤖 Для пользователей Telegram:
Найдите бота по его имени в Telegram.

Отправьте команду /start.

Следуйте инструкциям бота для создания нового заказа.

После создания вы получите номер заказа и сможете отслеживать его статус.

🖥️ Для курьеров и администраторов:
Перейдите по адресу веб-интерфейса (http://ваш_сайт/orders).

Авторизуйтесь (если реализовано) или используйте ссылку с параметром для просмотра.

Курьер увидит список своих заказов с возможностью изменить статус.

Администратор увидит полный список всех заказов с расширенными фильтрами.
